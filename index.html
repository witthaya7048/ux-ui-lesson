เมื่อเรียนจบ นักศึกษาสามารถอธิบาย UX/UI วิเคราะห์ความต้องการของธุรกิจ จัดลำดับเนื้อหา และออกแบบ Wireframe สำหรับคอมพิวเตอร์และมือถือได้

1. วิเคราะห์

ระบุกลุ่มเป้าหมายและเป้าหมายของธุรกิจ

2. ออกแบบ

จัดวางโครงสร้างเว็บไซต์ตามหลัก UX/UI

3. นำเสนอ

อธิบายเหตุผลในการออกแบบ Wireframe

เว็บไซต์ที่ดีควรมีอะไรบ้าง?

Layout (การจัดวาง), Color (สี), Typography (ตัวอักษร), Navigation (เมนู), Content (เนื้อหา) และ Responsive Design (รองรับหลายหน้าจอ)

01 — UX กับ UI ต่างกันอย่างไร?

UX — User Experience

ประสบการณ์การใช้งาน เน้นให้ผู้ใช้ทำสิ่งที่ต้องการได้ง่าย รวดเร็ว และไม่สับสน

ตัวอย่าง: ลูกค้าสั่งกาแฟสำเร็จได้ภายในไม่กี่ขั้นตอน

UI — User Interface

ส่วนติดต่อผู้ใช้ เช่น สี ปุ่ม ไอคอน ภาพ และตัวอักษรที่มองเห็น

ตัวอย่าง: ปุ่มสั่งซื้อเด่น อ่านง่าย และกดสะดวก

ชวนคิดในห้องเรียน

เว็บไซต์ร้านกาแฟสวยมาก แต่ลูกค้าต้องกด 8 ครั้งกว่าจะสั่งซื้อสำเร็จ — ปัญหาหลักคือ UX หรือ UI?

UX เพราะขั้นตอนใช้งานซับซ้อน แม้หน้าตาจะสวยงาม

02 — หลักการออกแบบ UX/UI

ใช้งานง่าย

ปุ่มสำคัญมองเห็นชัด ไม่ซ่อนขั้นตอนที่จำเป็น

ลำดับข้อมูลชัดเจน

หัวข้อหลักใหญ่กว่าเนื้อหารอง และจัดกลุ่มข้อมูลที่เกี่ยวข้องกัน

สม่ำเสมอ

รูปแบบเมนู ปุ่ม และสีเป็นแนวเดียวกันทั้งเว็บไซต์

Responsive

หน้าเว็บปรับตามจอมือถือ แท็บเล็ต และคอมพิวเตอร์

เข้าถึงได้

ตัวหนังสืออ่านง่าย สีตัดกันชัด และใช้งานด้วยคีย์บอร์ดได้

มีการตอบสนอง

เมื่อกดสั่งซื้อควรมีข้อความยืนยันหรือแสดงสถานะ

03 — Wireframe คืออะไร?

Wireframe คือแบบร่างโครงสร้างหน้าเว็บไซต์ ใช้กล่อง เส้น และข้อความแทนส่วนต่าง ๆ เพื่อวางตำแหน่งก่อนตกแต่งสีหรือเขียนโค้ดจริง

Wireframe = โครงร่างMockup = หน้าตาเสมือนจริงPrototype = แบบจำลองที่โต้ตอบได้

04 — ขั้นตอนออกแบบ Wireframe ตามโจทย์ธุรกิจ

  1. วิเคราะห์ธุรกิจ: ขายอะไร และต้องการให้เว็บไซต์ช่วยเรื่องใด
  2. กำหนดผู้ใช้: ใครจะเข้ามาใช้งาน มีความต้องการอะไร
  3. กำหนดฟังก์ชัน: ค้นหา สั่งซื้อ จองคิว หรือติดต่อ
  4. จัดลำดับข้อมูล: อะไรควรอยู่ด้านบน กลาง และล่าง
  5. วาด Wireframe: ใช้กระดาษหรือ Figma, Canva, diagrams.net
  6. ทดสอบ: ให้เพื่อนอธิบายวิธีใช้งาน แล้วปรับแก้จุดที่สับสน

05 — กิจกรรมปฏิบัติ: ออกแบบ Wireframe

เวลา 60–90 นาที • เลือกโจทย์ธุรกิจหนึ่งประเภทแล้วออกแบบหน้าแรกทั้ง Desktop และ Mobile

ข้อกำหนดชิ้นงาน

  1. ชื่อธุรกิจและกลุ่มเป้าหมาย
  2. วัตถุประสงค์เว็บไซต์อย่างน้อย 2 ข้อ
  3. Header และ Navigation
  4. ส่วนเนื้อหาหลักอย่างน้อย 3 ส่วน
  5. ปุ่ม CTA อย่างน้อย 1 ปุ่ม
  6. Footer พร้อมช่องทางติดต่อ
  7. Wireframe Desktop และ Mobile พร้อมเหตุผลการจัดวาง

ส่งงาน: ไฟล์ PDF หรือ PNG พร้อมคำอธิบายแนวคิด
